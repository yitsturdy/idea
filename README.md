## 機能一覧
### 👤 1. 管理者（Admin）機能

| 機能     | 内容                            | 技術アピールポイント             |
| ------ | ----------------------------- | ---------------------- |
| 課題図書登録 | 書籍タイトル・著者・概要・ISBN・購入リンクを登録    | CRUD API設計・DB操作の基本を網羅  |
| 受講者管理  | ユーザーアカウント作成・一覧表示・削除           | ロールベース認証・RESTful API設計 |
| タスク作成  | 「読む」「感想を書く」「行動を書く」の3ステップタスク作成 | データモデリング力・柔軟な拡張性       |
| 進捗確認   | 各受講者の進捗ステータスと提出内容確認           | 集約クエリ／リレーション設計スキル      |
| コメント投稿 | 提出された感想・行動へのコメント機能            | 双方向API・非同期通信の実装力       |

### 👩‍🎓 2. 受講者（User）機能

| 機能       | 内容                    | 技術アピールポイント       |
| -------- | --------------------- | ---------------- |
| 課題図書一覧   | アサインされた課題図書の一覧・詳細閲覧   | API連携・SPAでの状態管理  |
| 感想投稿     | 書籍の感想・要約をMarkdownで投稿  | 入力フォーム／バリデーション実装 |
| 行動レポート投稿 | 学びを基にした行動内容を記録        | DB設計・フォームデータ送信処理 |
| 進捗ステータス  | 「読了 → 感想 → 行動」の進捗バー表示 | ロジック処理＋UI連動の設計力  |
| コメント閲覧   | 管理者からのフィードバックを確認      | 認証済みユーザー専用API制御  |

### 🔐 3. 共通機能（Admin／User共通）

| 機能    | 内容                    | 技術アピールポイント      |
| ----- | --------------------- | --------------- |
| 認証機能  | JWTを用いたログイン／ログアウト機能   | セキュリティ設計の理解     |
| 権限管理  | 管理者／受講者のロール別画面制御      | 認可・ルーティング制御の基礎  |
| UI／UX | SPA構成（Vue.js）による非同期UI | フロント・バック分離設計の実践 |

### 🧠 構成イメージ

| 画面名        | 主な要素                 |
| ---------- | -------------------- |
| ログイン画面     | メール・パスワード入力、JWT発行    |
| 管理者ダッシュボード | 課題図書一覧／登録、受講者一覧、進捗確認 |
| 課題図書詳細画面   | タスク内容と進捗表示、コメント確認    |
| 感想投稿画面     | 感想フォーム、送信ボタン         |
| 行動レポート画面   | 行動内容フォーム、送信ボタン       |
| マイページ      | 自分の提出状況・進捗バー表示       |

### ✅ アピールポイントまとめ

| 観点            | 内容                                  |
| ------------- | ----------------------------------- |
| **バックエンド実装力** | Laravel（PHP）＋REST API設計＋JWT認証＋RDB設計 |
| **インフラ理解**    | Dockerでローカル構築、AWS上でデプロイ可能な構成        |
| **SPA設計**     | Vue.jsでの状態管理・API連携・非同期通信処理          |
| **実務的な設計思考**  | 拡張性を考慮したDBスキーマ・ロール設計・CRUD整理         |
| **UX視点の提案力**  | 「感想→行動」フローというビジネスロジック設計             |
